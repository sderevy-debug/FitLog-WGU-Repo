# FitLog 

General Features:
- Creating new fitness plans
- Viewing created plans
- Have plans be broken down into days
- Assign plans to days using a calender or a date
- Assign rest days using a calender or a date
- Allow the user to log whether they've completed a workout if the current day is a workout day
- Using a database to store user data for persistant storage
- Code structure fits Vercels expected structure
- Basic User Login to seperate data
- Light/Dark Mode Toggle
- Import workout plans using JSON file
